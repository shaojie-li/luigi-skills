# 数据列表

先检查项目安装的 TanStack Table 版本、列定义范例和后端接口约定；按该版本的文档实现，不混用不同主版本 API。

明确分页、排序和筛选分别由客户端还是服务端执行。服务端分页只拿到一页数据时，不再把该页当成完整数据进行客户端全局排序或筛选。记录页码是从 0 还是 1 开始，以及总数未知时是否支持跳到最后一页。

使用稳定业务 ID 标识行，不用显示索引追踪跨页选择。区分选择当前页、已加载行和全部查询结果；跨页选择需要接口和产品语义支持，不能默认等价。

根据项目约定将需要保留的查询状态同步到 URL 或页面状态；更换筛选或页大小时处理页码重置。异步请求避免旧响应覆盖新筛选结果，优先使用项目已有数据请求层。

列定义、工具栏、分页与表格展示保持可组合，不引入统一包办请求和业务操作的万能组件。展示加载、无结果、请求失败与重试；数据为空时保留操作上下文。

验证本次改动涉及的筛选重置、页边界、行 ID、选择语义和请求失败。虚拟化仅在数据规模或实测性能需要时引入。
