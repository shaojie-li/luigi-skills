# React 表单

读取项目现有表单范例与校验规则。React Hook Form 管理字段状态；UI 组件负责 label、提示、错误展示和可访问性。不要同时维护一套重复的 useState 表单状态。

原生输入沿用项目的 register 用法；需要适配的受控组件使用 Controller 或 useController，核对 onChange、value、onBlur 和 ref 的语义，避免同一输入同时注册两次。不要假设 Select 的回调与原生 input 事件相同。

明确输入值与业务值的边界，尤其是空字符串、数字、日期、可空字段及多选数组。已经使用 schema 校验时复用该规则，不在 UI 再复制一套相互冲突的约束。前端校验不能替代服务端校验。

提交期间控制重复操作；接口字段错误映射到对应字段，非字段错误提供可见提示，失败保留用户输入。没有服务端确认前不要显示成功。异步载入初始数据时区分首次初始化与用户正在编辑的值，避免重新请求后清掉未保存内容。

按改动风险验证至少相关的合法输入、非法输入、服务端失败及异步状态。测试用户可观察结果，不只断言内部 hook 被调用。
